# Module 1 Assessment

## Scope: ROS 2 Fundamentals and Communication
Students will be assessed on their understanding of the core concepts covered in Chapters 1-4.

| Topic              | Learning Objectives                                                                                                    | Assessment Method               |
| :----------------- | :--------------------------------------------------------------------------------------------------------------------- | :------------------------------ |
| ROS 2 Core         | Define Node, Package, and Workspace. Explain colcon build system.                                                    | Short Answer / Multiple Choice  |
| Topics             | Differentiate Publisher vs. Subscriber. Define QoS (Quality of Service) and its importance.                              | Code Tracing / Conceptual Question |
| Services           | Explain the Client-Server model. Identify when to use a Service over a Topic or Action.                                | Scenario-based Problem          |
| Actions            | Explain the Goal-Feedback-Result structure. Describe the role of `rclpy.action`.                                     | Short Answer / Code Implementation |
| Robot Definition   | Explain the purpose of URDF and its core components (Links and Joints). Describe the purpose of a Launch File in system composition. | Definitions / Diagram Labeling  |
