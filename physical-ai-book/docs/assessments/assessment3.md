# Module 3 Assessment

This assessment requires you to integrate the core components of the NVIDIA Isaac platform with the ROS 2 Navigation Stack (Nav2) to successfully navigate a complex, dynamic environment using a humanoid model.

## 🎯 Goal
Implement a full perception and navigation pipeline to make the humanoid robot autonomously travel from a start point to a goal point while avoiding both static and dynamic obstacles in a simulated warehouse or factory environment within NVIDIA Isaac Sim.

## 📝 Required Components & Steps
### Isaac Sim Scene Setup:
*   Start with a pre-built Isaac Sim environment (e.g., a warehouse or factory).
*   Spawn a humanoid robot model (e.g., 1X, Digit) and an associated mobile base (if applicable for navigation).
*   Introduce dynamic obstacles (e.g., a "people simulator" or a moving AMR).

### Isaac ROS Perception Stack:
*   Integrate and configure the Isaac ROS VSLAM package to use the robot’s stereo cameras and IMU for real-time visual localization.
*   Integrate and configure Isaac ROS Nvblox to generate an accurate 3D occupancy grid and a 2D costmap slice from the robot’s depth/RGB data.

### ROS 2 Nav2 Stack Configuration:
*   Configure the Nav2 stack to use the VSLAM pose output for localization.
*   Configure Nav2’s global and local costmaps to subscribe to the costmap generated by Nvblox.
*   Define a basic Behavior Tree to execute the main navigation task (`FollowPath`, `ComputePathToPose`, etc.).

### Navigation Task:
*   Set a navigation goal that forces the robot to navigate through a narrow passage or around a moving dynamic obstacle.
*   Record a video demonstrating the robot autonomously reaching the goal without collisions.

## ✅ Submission Requirements
Your final submission must include:
*   A recorded video (max 3 minutes) of the robot successfully completing the dynamic navigation task in Isaac Sim.
*   Configuration files for your Isaac ROS nodes (VSLAM, Nvblox) and your Nav2 stack (yaml files for planners, controllers, and costmaps).
*   A brief technical report (max 500 words) detailing:
    *   How your perception data (Nvblox costmap) is fed to the Nav2 local costmap.
    *   The achieved performance (e.g., perceived latency or FPS) for the VSLAM node.
    *   Any specific challenges encountered when adapting Nav2 for the humanoid and how you solved them.

This assessment tests your ability to create a fully integrated, high-performance AI perception and control system for autonomous humanoid operation.
