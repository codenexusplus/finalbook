# RAG Query API with FastAPI, Cohere, and Qdrant

This directory contains the FastAPI application for the Retrieval-Augmented Generation (RAG) query API. It allows users to ask questions about content ingested from various sources (local files or Vercel URLs) and receive answers generated by a Cohere LLM, along with source references from Qdrant.

## New Feature: Vercel URL Ingestion
The system now supports ingesting content directly from Vercel-hosted websites, including:
- Automatic sitemap.xml parsing
- Domain correction for localhost URLs in sitemaps
- Web scraping fallback for sites without sitemaps
- Content extraction from HTML pages

## Setup

### Prerequisites

- Python 3.11+
- Access to Cohere and Qdrant Cloud to obtain API keys.
- A populated Qdrant collection (created by the ingestion pipeline).

### Local Setup

1.  **Navigate to the `fastapi-rag` directory:**
    ```bash
    cd fastapi-rag
    ```

2.  **Create a Virtual Environment (recommended):**
    ```bash
    python -m venv venv
    # On Windows: venv\Scripts\activate
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Configure Environment Variables:**
    Create or update the `.env` file in this directory with your API keys and service URLs:

    For local file ingestion:
    ```
    COHERE_API_KEY="your-cohere-api-key"
    QDRANT_URL="https://your-qdrant-cloud-url.qdrant.tech:6333"
    QDRANT_API_KEY="your-qdrant-api-key"
    DOCS_PATH="../physical-ai-book/docs"
    # NEON_DATABASE_URL="your-postgres-db-url"  # Optional: only needed if using PostgreSQL
    ```

    For Vercel URL ingestion:
    ```
    COHERE_API_KEY="your-cohere-api-key"
    QDRANT_URL="https://your-qdrant-cloud-url.qdrant.tech:6333"
    QDRANT_API_KEY="your-qdrant-api-key"
    VERCEL_URL="https://your-vercel-site.vercel.app"
    # NEON_DATABASE_URL="your-postgres-db-url"  # Optional: only needed if using PostgreSQL
    ```
    **Note**: Ensure `QDRANT_URL` includes the port if required by your Qdrant instance.

## Data Ingestion

### Ingest from Local Files
Run the following command to ingest documents from a local directory:
```bash
python ingest.py
```

### Ingest from Vercel URL
Set the `VERCEL_URL` in your `.env` file and run:
```bash
python ingest.py
```

### Alternative Web Ingestion
There's also a dedicated web ingestion script:
```bash
python ingest_web.py
```

## Execution

### Run the Application

The main API logic is in `app.py`.

```bash
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```
This command starts the Uvicorn server. The `--reload` flag is useful for development as it automatically restarts the server on code changes.

### Access the API Documentation

Once the server is running, you can access the interactive API documentation (Swagger UI) at:

```
http://localhost:8000/docs
```
You can use this interface to test the `/query` endpoint.

### Example API Call (using curl)

```bash
curl -X POST "http://localhost:8000/query" \
-H "Content-Type: application/json" \
-d
'{ "question": "What is the purpose of a ROS 2 node?" }'
```

This will send a sample question to the API and return the generated answer and source URLs.
