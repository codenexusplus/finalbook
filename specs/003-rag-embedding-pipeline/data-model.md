# Data Model: Embedding Pipeline

**Date**: 2025-12-15
**Feature**: [Embedding Pipeline Setup](spec.md)

This document defines the data structures used in the embedding pipeline, specifically for the objects stored in the Qdrant vector database.

## 1. Qdrant Point Structure

The core data entity is a **Qdrant Point**. Each point represents a single text chunk that has been extracted from a source URL and converted into a vector embedding.

### Fields

-   **`id`** (UUID)
    -   Description: A unique identifier for the point. This will be generated during the ingestion process to ensure each text chunk can be individually referenced.
    -   Type: `string` (UUID format)

-   **`vector`** (Array of Floats)
    -   Description: The dense vector representation of the text chunk, generated by the Cohere embedding model (`embed-english-v3.0`).
    -   Type: `float[]`
    -   Size: `1024`

-   **`payload`** (Object)
    -   Description: A JSON object containing the original content and metadata associated with the vector.
    -   Fields:
        -   **`text`** (`string`): The raw text content of the chunk. This is the content that was used to generate the vector.
        -   **`source`** (`string`): The absolute URL from which the text chunk was originally extracted. This allows for tracing the origin of the information.
        -   **`chunk_id`** (`integer`): The sequential index of the chunk within its source document.

### Example Qdrant Point

```json
{
  "id": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
  "vector": [0.12, 0.45, ..., -0.08],
  "payload": {
    "text": "This is a chunk of text from the documentation. It discusses the core principles of ROS 2 nodes.",
    "source": "https://finalbook-ss4z.vercel.app/docs/module-1-ros2/ch2-ros2-architecture",
    "chunk_id": 3
  }
}
```

## 2. Qdrant Collection Configuration

-   **Collection Name**: `rag_embedding`
-   **Vector Parameters**:
    -   **Size**: `1024` (to match Cohere's `embed-english-v3.0` model)
    -   **Distance Metric**: `Cosine` (A standard and effective metric for measuring similarity between text embeddings)
